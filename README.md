# ARS Tech Solutions website

A responsive React and Vite marketing website for ARS Tech Solutions.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. To create a production build, run `npm run build`.

## Contact form

The form includes client-side validation and a demo success state. Its markup includes Netlify Forms attributes so a production submission handler can be added later. For a live deployment, connect Netlify Forms or replace the submit handler with a serverless API call.
